# Metabolic Simulations

This directory contains scripts for performing **constraint-based metabolic simulations** using genome-scale metabolic models.

## Contents

- Flux Balance Analysis (FBA)
- Flux Variability Analysis (FVA)
- Growth simulations
- Metabolite production simulations
- Medium and environmental condition analysis
- Syngas composition simulations
- Flux distribution analysis

## Simulation Methods

### Flux Balance Analysis

FBA is used to calculate optimal metabolic flux distributions under defined constraints and environmental conditions.

### Flux Variability Analysis

FVA is used to determine the feasible flux range of individual reactions while maintaining a defined fraction of the optimal objective value.
