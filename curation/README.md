# Model Curation

This directory contains scripts for the **manual and computational curation of genome-scale metabolic models**.

## Contents

- Reaction curation
- Metabolite curation
- Reaction directionality analysis
- Gene-protein-reaction (GPR) association analysis
- Reaction and metabolite annotation
- Gap-filling
- Model refinement

## Objectives

The main goal is to improve model consistency, completeness, and biological representativeness before downstream metabolic simulations.

> 🚧 **Work in progress:** Curation workflows are currently being organized.
