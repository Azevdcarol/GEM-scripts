# Visualization

This directory contains scripts for the **visualization and graphical analysis of metabolic simulation results**.

## Contents

- Heatmaps
- Ternary plots
- Flux distribution plots
- Comparative plots
- Simulation result visualization

## Tools

- Python
- Matplotlib
- Pandas
- NumPy

The scripts are intended to facilitate the interpretation and presentation of metabolic modeling results.

> 🚧 **Work in progress:** Visualization scripts and examples are being added progressively.
