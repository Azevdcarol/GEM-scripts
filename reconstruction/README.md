# Model Reconstruction

This directory contains scripts and workflows related to the reconstruction of **genome-scale metabolic models (GEMs)**.

## Contents

- Model reconstruction from genome sequences
- Genome annotation and functional information processing
- Reconstruction using automated tools such as CarveMe and gapseq
- Initial model generation and preprocessing

## Tools

- CarveMe
- gapseq
- Python
- COBRApy

> 🚧 **Work in progress:** Additional reconstruction workflows will be added as the repository develops.
